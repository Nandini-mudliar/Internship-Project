# Live Spam Message Detector Using Python and Machine Learning

## 📌 Project Overview

The **Live Spam Message Detector** is a Python-based project that identifies whether a text message is spam, legitimate, or potentially related to phishing. It uses an online text-classification API to analyze user-provided messages and return a predicted category.

The project is developed using Python and Google Colab, making it easy to run without installing additional software on a local computer.

## 🎯 Objectives

- Detect spam messages using an online classification API.
- Identify potentially suspicious or phishing-related messages.
- Provide an interactive way for users to check their messages.
- Display the predicted category and confidence score when available.
- Demonstrate the practical application of Python and machine learning in cybersecurity.

## 🛠️ Technologies Used

- **Python** — Core programming language.
- **Google Colab** — Cloud-based development environment.
- **Requests** — Sends HTTP requests to the online API.
- **Open Text Shield API** — An external service used for message classification.

## ⚙️ How It Works

1. The user enters a text message into the program.
2. Python sends the message to the classification API.
3. The API analyzes the text and returns a prediction.
4. The program displays the result as Spam, Not Spam (Ham), or Phishing when supported by the API response.
5. A confidence score is displayed when provided by the service.

## ✨ Key Features

- User-friendly message input.
- Real-time API-based classification.
- Spam and phishing detection categories.
- Confidence score display when available.
- Error handling for connection failures and timeouts.
- No local machine learning model training required.

## ▶️ How to Run the Project

1. Download the project notebook.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload the `.ipynb` file.
4. Execute the notebook cells in order.
5. Enter a message when prompted.
6. View the classification result.

An active internet connection and availability of the external API are required.

## 🔮 Future Enhancements

- Integrate URL reputation checking to identify potentially malicious links.
- Develop a simple web interface using Streamlit or Gradio.
- Add message history and classification statistics.
- Compare predictions from multiple classification services.
- Improve evaluation using a labelled SMS dataset.

## ⚠️ Limitations

The classification result is an automated prediction and may not always be accurate. A message classified as legitimate is not guaranteed to be safe. The project does not independently verify every URL contained in a message. User-provided text is transmitted to an external service, so confidential information should not be submitted.

## 🎓 Learning Outcomes

This project provides practical experience with Python programming, API integration, HTTP requests, JSON responses, text classification, and basic cybersecurity concepts.
